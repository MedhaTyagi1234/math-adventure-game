Maths Adventure Game 🎮🌍

A simple educational game that turns Maths into a fun, story-based learning experience instead of traditional worksheets and tests.

🎯 Features

- Story-based gameplay for learning Maths
- Interactive levels and progression system
- Reward-based learning instead of exams
- Designed to make Maths feel more engaging and less stressful

💡 Motivation

Maths is often associated with fear, pressure, and repetitive practice.
This project is an attempt to explore a different approach—where learning happens through play, exploration, and interaction.

As a developer, I also relate to this struggle, which inspired me to build a more engaging learning experience for younger audiences.

🚀 Status

Playable version completed. Further improvements and updates will be added over time.

🙏 Note

This project is built with the intention of making learning more enjoyable and accessible for the next generation.

Feedback and suggestions are welcome.
